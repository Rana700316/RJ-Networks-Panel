RJ NETWORKS - Render Ready

1) GitHub repository mein index.html aur config.js upload karein.
2) Render > New Static Site > Public Git Repository.
3) Apni GitHub repository select karein.
4) Build command khali rakhein.
5) Publish Directory: .
6) Deploy Static Site dabayein.

NOTE: config.js mein apni Supabase URL aur Publishable/Anon key dalni hogi.
